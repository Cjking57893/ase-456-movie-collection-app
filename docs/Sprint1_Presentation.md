# Sprint 1 Review
(9/7/2025 - 10/14/2025)
Cody King

---

### Overview
An app designed to help users keep track of movie collection. Uses the TMDB API for movie information and allows users to store information about collection.

---

### Sprint 1 Features

- **Authentication** - User signup/login pages and functionality complete using Firebase Authentication
- **Movie Collection** - CRUD features complete to track and store movies in collection and information about them
- **TMDB API Integration** - Movie data is being pulled from TMDB allowing user to not have to enter in everything manually
- **Search Feature** - Search Feature allows for users to search for a movie and results will pop up from TMDB
- **Firestore DB Integration** - Information about user's collection being stored in Firestore DB
